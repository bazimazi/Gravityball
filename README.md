# Gravityball

You do not move the ball. You turn gravity.

Left side of the screen rotates the pull counter-clockwise. Right side rotates it clockwise. From a downward pull, that means the left side sends the ball right, and the right side sends it left — you are turning a force, not steering.

## Play

```bash
npm install
npm run dev
```

Then open the local URL on a phone, or in a narrow browser window. Keyboard: A / Left and D / Right turn gravity, R restarts, Esc pauses.

```bash
npm test
npm run build
```

## What is here

A hand-built campaign of ten worlds, from the first tap through orbits and collapse. Physics is a fixed 120 Hz step so retries, ghosts, and replays follow the same line. Levels are data. Medals mean something: finish, a tighter line, a harder constraint, a perfect one. Everything you do feeds insight and a rank: each rank pays a fragment, some carry a look you cannot buy, and gold or perfect on every chamber of a world earns its seal.

Also on the map, once the campaign opens them: a shared daily chamber, endless rooms, Gravity Run (pick a modifier between rooms; nothing here touches the campaign), and a sandbox.

Progress stays on this device. There is no energy, no wait, and no paid power.
